# MT4Service — 5. Streaming Methods

> The five server streams, with **clean names** (`Stream*`) over the raw `On*` calls. Each returns a `(<-chan *pb.…Data, <-chan error)` pair — read frames with `select` and cancel the context to stop. See [gRPC Streaming](../All_Guides/GRPC_STREAM_MANAGEMENT.md).

> `MT4Sugar` wraps the tick / profit / tickets streams as `SubscribeQuotes` / `WatchProfit` / `WatchTickets`.

---

## `StreamTicks(ctx, symbols)`

```go
func (s *MT4Service) StreamTicks(ctx context.Context, symbols []string) (<-chan *pb.OnSymbolTickData, <-chan error)
```

Live tick stream. Frame: `GetSymbolTick()` → `OnSymbolMqlTickInfo` (`GetSymbol()`, `GetBid()`, `GetAsk()`, `GetLast()`, `GetTime()`).

```go
ctx, cancel := context.WithTimeout(ctx, 10*time.Second)
defer cancel()
data, errs := svc.StreamTicks(ctx, []string{"EURUSD"})
for {
    select {
    case d := <-data:
        t := d.GetSymbolTick(); fmt.Println(t.GetSymbol(), t.GetBid(), t.GetAsk())
    case err := <-errs:
        if err != nil { return err }
    case <-ctx.Done():
        return nil
    }
}
```

## `StreamTrades(ctx)`

```go
func (s *MT4Service) StreamTrades(ctx context.Context) (<-chan *pb.OnTradeData, <-chan error)
```

Live order/trade events (new / updated / removed orders) for the account.

---

## `StreamOpenedTickets(ctx, intervalMs)`

```go
func (s *MT4Service) StreamOpenedTickets(ctx context.Context, intervalMs int32) (<-chan *pb.OnOpenedOrdersTicketsData, <-chan error)
```

Open-order ticket list, pushed every `intervalMs`. Frame: `GetPositionTickets()`, `GetPendingOrderTickets()` (pre-split).

```go
data, _ := svc.StreamOpenedTickets(ctx, 1000)
d := <-data
fmt.Printf("%d positions, %d pendings\n", len(d.GetPositionTickets()), len(d.GetPendingOrderTickets()))
```

---

## `StreamOpenedProfit(ctx, intervalMs)`

```go
func (s *MT4Service) StreamOpenedProfit(ctx context.Context, intervalMs int32) (<-chan *pb.OnOpenedOrdersProfitData, <-chan error)
```

Per-order floating profit + an account snapshot, every `intervalMs`. Frame: `GetOpenedOrdersWithProfitUpdated()`, `GetAccountInfo()` (`GetEquity()`, `GetProfit()`, `GetMarginLevel()`).

```go
data, _ := svc.StreamOpenedProfit(ctx, 1000)
if d := <-data; d.GetAccountInfo() != nil {
    fmt.Printf("equity %.2f floating %+.2f\n", d.GetAccountInfo().GetEquity(), d.GetAccountInfo().GetProfit())
}
```

## `StreamConnectState(ctx, terminalIds)`

```go
func (s *MT4Service) StreamConnectState(ctx context.Context, terminalIds []string) (<-chan *pb.ConnectStateData, <-chan error)
```

Terminal connection-state events (pass `nil` for this terminal). Frame: `GetState()` (`"Connected"`, `"WrongPassword"`, …), `GetIsConnected()`, `GetServer()`, `GetAccount()`.

```go
data, _ := svc.StreamConnectState(ctx, nil)
for d := range data {
    if !d.GetIsConnected() { /* pause trading */ }
}
```
